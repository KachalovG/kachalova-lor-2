# Проверка локальной версии

18 октября 2026. Проверена рабочая папка `src`, без сборки `dist`.

## Автоматическая проверка

`node tools/check.mjs` — PASS.

- Один H1, один description, русский язык, канонический URL.
- JSON-LD разбирается без ошибок, описывает реального врача и места приёма.
- Нет повторных id и несуществующих внутренних якорей.
- Все локальные изображения, CSS, JS, файлы из srcset и шрифты существуют.
- Изображения имеют alt, width и height.
- Все три пользовательские ссылки записи одинаковы в карточках клиник и диалоге.
- JavaScript меньше 5 КБ. Внешние runtime-скрипты отсутствуют.
- `node --check src/js/main.js` — успешно.
- `dist` отсутствует.

## Визуальная и интерактивная проверка в браузере

- Ширины 320, 390, 768, 1024 и 1440 пикселей.
- Найденное переполнение названия клиники на 320 пикселях устранено, повторная проверка — без горизонтального переполнения.
- Первый экран и карточки клиник проверены на широком экране.
- Мобильное меню открывается, после выбора раздела закрывается.
- Раздел образования раскрывается, текст доступен.
- Окно записи открывается с основной и мобильной кнопок.
- Escape закрывает диалог, фокус возвращается на кнопку открытия.
- Мобильный диалог помещается по ширине, все три ссылки доступны.
- После прокрутки загружены все четыре фотографии.
- Ошибок и предупреждений JavaScript в браузере не обнаружено.

## Вес

После форматирования исходников: около **186 КиБ** для HTML, CSS, JS, трёх шрифтов и большого главного фото (без сжатия, без отложенных фото). HTML + CSS + JS с gzip: **13 326 байт**. Это расчёт по реальным файлам, не замер Lighthouse. Браузер может заранее загрузить близкие к экрану lazy-изображения.

Публичный сайт не заменялся. Lighthouse, полевые Core Web Vitals, доступность внешних сервисов записи и индексирование на production-хостинге не проверялись. Ссылки записи проверены на точное соответствие сообщению пользователя; записи на приём не создавались.

## Для просмотра

Локальный сервер: http://127.0.0.1:4173. Если сервер остановлен, запустить `node tools/serve.mjs` из корня проекта. Дополнительная установка зависимостей не нужна.
