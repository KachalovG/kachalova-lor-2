# Евгения Качалова — ЛОР-врач в Москве

Новый статический сайт. Содержание перенесено с https://www.kachalova-lor.site/ и скриншотов пользователя. Использованы четыре предоставленные фотографии. Все три ссылки записи взяты из последнего сообщения пользователя.

## GitHub и публикация

- Репозиторий: https://github.com/KachalovG/kachalova-lor-2
- Сайт: https://kachalovg.github.io/kachalova-lor-2/
- `main` содержит рабочие исходники, документацию и инструменты.
- `gh-pages` содержит только содержимое `src` и используется GitHub Pages. Файл `.nojekyll` отключает обработку Jekyll.
- По прямой команде владельца сайт опубликован на GitHub Pages без создания локальной папки `dist`.
- Canonical, Open Graph, JSON-LD и sitemap настроены на текущий адрес GitHub Pages. При подключении собственного домена их нужно обновить согласованно.
- Рабочие изменения в `main` не публикуются автоматически: для обновления сайта требуется обновить ветку `gh-pages` из зафиксированной папки `src`.

## Структура

```text
src/                     Рабочая папка сайта
  index.html             Содержание, метатеги, JSON-LD
  css/styles.css         Дизайн и адаптивная вёрстка
  js/main.js             Меню и окно выбора клиники
  assets/images/         Оптимизированные фотографии WebP
  assets/fonts/          Локальные шрифты WOFF2 и лицензии
  assets/favicon.svg     Иконка сайта
  robots.txt
  sitemap.xml
tools/                   Локальный сервер, проверки, подготовка файлов
docs/                    Источник содержания и заметки о проверке
package.json             Команды без зависимостей
```

**Папка `dist` не создана. Команды сборки пока нет.** Создать и собрать её можно только после проверки сайта владельцем и его прямой команды. Рабочий сайт находится целиком в `src`; `docs` и `tools` не нужно публиковать.

## Локальный просмотр

Из корня проекта:

```sh
npm run dev
# Или без npm:
node tools/serve.mjs
```

Открыть http://127.0.0.1:4173. Для обычного просмотра не нужна установка пакетов. Можно также открыть `src/index.html` напрямую, но предпочтительнее локальный сервер. Остановка сервера — Ctrl+C.

Проверки:

```sh
npm run check
# Или без npm:
node tools/check.mjs
```

## Что работает

- Адаптивная страница, навигация и мобильное меню.
- Раскрывающиеся направления помощи, образование и опыт.
- Окно выбора клиники с клавиатурной навигацией и закрытием Escape.
- Реальные внешние ссылки записи, телефон, почта, Telegram и WhatsApp.
- Содержание, контакты, ссылки и раскрывающиеся разделы доступны без JavaScript.
- Формы сбора персональных данных и сторонние трекеры не используются.

## Производительность

HTML отдаётся готовым, без клиентского рендеринга и фреймворка. Шрифты размещены локально, без запросов к Google Fonts. Фотографии WebP с адаптивными размерами; главное фото получает высокий приоритет, остальные загружаются отложенно. Все изображения имеют заданные размеры. Анимации учитывают `prefers-reduced-motion`.

`tools/prepare-assets.py` нужен только для повторной подготовки фотографий и шрифтов. Для него необходимы Python, Pillow, fonttools и brotli; сайт не зависит от Python. Исходные фото читаются из папки Downloads, оригиналы не изменяются.

## SEO

В HTML подготовлены один title и description, один H1, канонический URL, Open Graph, Twitter Card, русский язык документа и Schema.org: WebSite, WebPage, Person и места работы MedicalClinic. Ключевые намерения: «ЛОР в Москве», «ЛОР-врач взрослым и детям», имя врача, приём возле Аминьевской, Сокола и Аэропорта. Рейтинги и отзывы не выдуманы.

После одобрения и публикации: проверить HTTPS и перенаправление на единственный основной домен, включить Brotli/gzip и корректное кеширование, передать sitemap в Яндекс Вебмастер и Google Search Console, выполнить замеры на реальном хостинге. Код не гарантирует позиции в поиске; скорость и доступность сервера также имеют значение.

Источники рекомендаций: [Google — метаданные](https://developers.google.com/search/docs/fundamentals/get-started-developers), [Google — поддерживаемые метатеги](https://developers.google.com/search/docs/crawling-indexing/special-tags). `meta keywords` не добавлен: Google не использует его для ранжирования.
